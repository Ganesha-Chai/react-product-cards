# 🛍️ React Product Cards

A beginner-friendly React mini-project built to explore fundamental React concepts by creating reusable and dynamically rendered product cards.

## 📸 Project Preview

![React Product Cards Screenshot](./screenshots/product-cards.png)

## 🚀 Features

- Displays four product cards with product details.
- Dynamically renders product information using arrays.
- Displays original and discounted prices.
- Reusable components for cards and pricing.
- Custom inline styling using React.
- Flexbox-based layout and alignment.

## 🧠 React Concepts Learned

Through this mini-project, I practiced:

1. **Components:** Creating and organizing reusable React components.
2. **Props:** Passing data from parent components to child components.
3. **Array Handling:** Working with 1D and 2D arrays.
4. **Dynamic Rendering:** Accessing array elements using indexes to display product information.
5. **Dynamic Styling:** Applying inline CSS styles using JavaScript objects.
6. **Flexbox:** Aligning and arranging components horizontally.
7. **JSX:** Understanding JSX syntax and embedding JavaScript expressions.

## ⚙️ How to Run Locally

**1. Clone the repository**

```bash
git clone https://github.com/Ganesha-Chai/react-product-cards.git
```

**2. Navigate to the project directory**

```bash
cd react-product-cards
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the local URL**

```text
http://localhost:5173
```
